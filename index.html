Sobre os dados

A taxa de investimento (s) é estimada a partir da Formação Bruta de Capital Fixo — índice de volume, série 22102 do SGS/Banco Central, puxada ao vivo (com backup offline). O BCB não publica a razão FBCF/PIB como série pronta; por isso o índice real é ancorado na taxa média de investimento do Brasil (~17,5% do PIB, IBGE/Contas Nacionais), preservando as variações reais.

O crescimento é comparado com o IBC-Br (série 24364), proxy mensal do PIB. Material educativo — não é recomendação de investimento.

Arquivo único, funciona offline com o snapshot embutido. Dados ao vivo via API pública SGS do Banco Central.
